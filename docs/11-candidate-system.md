# Candidate System

## Purpose

The Candidate System allows students, graduates, and internship seekers to discover opportunities, apply, track applications, and improve employability using AI tools.

---

## Candidate Dashboard

Widgets

- Total Applications
- Accepted Applications
- Rejected Applications
- Pending Applications
- Recommended Internships
- Upcoming Interviews
- Recent Notifications

---

## Candidate Profile

Fields

Personal Information

- First Name
- Last Name
- Email
- Phone Number
- Profile Photo

Education

- Institution
- Degree
- Course
- Graduation Year

Skills

- Technical Skills
- Soft Skills

Experience

- Internship History
- Work Experience

Links

- LinkedIn
- Portfolio
- GitHub

---

## Saved Internships

Candidates can:

- Save internship
- Remove internship
- View saved internships

---

## Applications

Statuses

- Draft
- Submitted
- Under Review
- Shortlisted
- Interview Scheduled
- Accepted
- Rejected

---

## Candidate Permissions

Allowed

- View internships
- Apply
- Edit profile
- Upload CV
- Save internships
- Schedule interviews

Restricted

- Admin access
- Employer access
