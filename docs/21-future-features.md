# Long-Term Vision

InternConnect should evolve from:

↓

↓

↓

The platform should become the primary gateway connecting students, graduates, employers, recruiters, training providers, and educational institutions across Africa.

# Deferred Features

Do Not Build During MVP

- Mobile App
- Custom Video Calling Infrastructure
- AI Career Coach
- LMS
- Skill Testing
- Referral System
- Multi-Country Support
- Multi-Language Support
- Enterprise Suite

Reason:

Focus on achieving product-market fit before expanding scope.
