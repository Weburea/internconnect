# InternConnect

InternConnect is an AI-powered internship and graduate opportunity platform connecting candidates, employers, and administrators through a centralized internship management system.

Primary Users:

- Candidates
- Employers
- Administrators

Core Features:

- Internship discovery
- Internship applications
- Candidate profiles
- Employer recruitment tools
- AI-powered recommendations
- AI resume optimization
- Subscription plans
- Interview management
- Messaging system
- Analytics dashboards

Technology Stack:

- PHP 8.3+
- MySQL 8
- Tailwind CSS
- Alpine.js
- DeepSeek API
- Paystack
- Google OAuth
