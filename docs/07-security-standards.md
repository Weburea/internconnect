# Security Standards

Mandatory Requirements

- HTTPS only
- Prepared Statements only
- CSRF Protection
- XSS Protection
- Rate Limiting
- Session Regeneration
- File Validation
- Webhook Verification

Forbidden

- Raw SQL Queries
- Plain Password Storage
- Exposed API Keys
- Hardcoded Secrets

File Upload Rules

Allowed:

- PDF
- DOCX
- JPG
- PNG
- JPEG
- JPG
- PNG
- JPEG
- WEBP
- SVG

Maximum Size:

2MB
